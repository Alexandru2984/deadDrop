VERIFY THE CODE

Dead Drop is a website, so your browser downloads the encryption code from this server on every visit. This page lets you check that what you received matches the published, open-source code — and is honest about the limits of doing so from inside the page itself.

1. Does the served code match its manifest?

Every file this server sent is hashed in your browser and compared to /SHA256SUMS, the manifest committed to the public repository.

2. Does that manifest match the open-source repository?

Step 1 only proves the files agree with the manifest this same server handed you — a malicious server could serve a tampered bundle and a matching manifest and a doctored version of this very page. The check that a compromised server cannot fake is comparing the manifest against an independent copy — the public GitHub repo.

3. The honest ceiling

    
    
      
  • Reduce who you trust: load Dead Drop over its
        Tor onion address to cut Cloudflare out of the delivery path — then
        only the operator serves the code, not a TLS-terminating middlebox.
    • 
      
  • A website can't fully win this. If your adversary is the operator (or anyone
        who can coerce them), no in-page check is enough — the page is served by the same party.
        The real fix is code that is installed once and updated through a signed, reviewed channel:
        a browser extension that pins these hashes, or a native client. That is deliberately out of
        scope for a pure website, and stated here rather than hidden.
