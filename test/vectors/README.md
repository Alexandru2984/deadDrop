# Image fixture

`photo.avif` is a generated 30 × 20 RGB gradient, encoded locally with
libheif 1.21.2 and its AOM AV1 encoder at quality 80. Pixel `(x, y)` is
`(8*x, 12*y, 64)`. Its XMP includes the synthetic marker `AVIF-AUDIT-METADATA`.
It contains no real person's photo or identifying data.

The browser pair test uses this actual AVIF container to exercise JPEG
conversion. Decoder sniffing of a PNG with a HEIC MIME label no longer passes
the file signature check. This fixture is test data only; CI does not need
libheif or an AV1 encoder.

`ml-kem-768.json` is the existing NIST vector fixture, regenerated by
`scripts/fetch-mlkem-vectors.mjs` as described in `test/README.md`.
